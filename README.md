# 🌿 Sri Lankan Wildlife Web Application 

Welcome to the **Sri Lankan Wildlife** web project repository! This is an interactive and educational web platform built to showcase the rich biodiversity, unique fauna, national parks, and natural beauty of Sri Lanka.

---

## 🌐 Live Demo & Deployment
- 🔗 **Live Website:** [Click Here to Explore](https://geethmasandaruwani87-cyber.github.io/sri-lankan-wildlife/)
- 💻 **Source Code:** [GitHub Repository](https://github.com/geethmasandaruwani87-cyber/sri-lankan-wildlife)

---

## ✨ Key Features
- 🦁 **Animals Section:** Discover elephants, leopards, sloth bears, and other mammals endemic to Sri Lanka.
- 🦅 **Birds Section:** Overview of over 500 bird species including endemic species.
- 🏞️ **National Parks:** Highlights of famous sanctuaries like Yala, Wilpattu, and Sinharaja.
- 📸 **Gallery:** A beautiful photo collection celebrating island wildlife.
- 📱 **Responsive Design:** Clean, accessible layout built with semantic structure.

---

## 🛠️ Tech Stack Used
- **HTML5:** Semantic markup for multi-page site structure.
- **CSS3:** Custom styling, color schemes, and layout design.
- **GitHub Pages:** For live website hosting and deployment.
